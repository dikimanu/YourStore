# Security Policy & Defences

This document outlines the security architecture and threat defences implemented across YourStore, covering authentication, data integrity, access control, and API protection.

---

## Threats, Defences, and Implementation Locations

| Threat | Defence | Where in code |
| :--- | :--- | :--- |
| **Brute force and lockout** | Rate limiting via `authLimiter` (10 req/15 min/IP). Account locked for 15 minutes after 5 consecutive failed login attempts (`failedLoginCount >= 5`, `lockUntil`). | [`apps/api/src/middleware/rateLimit.ts`](file:///c:/Users/Admin/Downloads/YourStore/apps/api/src/middleware/rateLimit.ts)<br>[`apps/api/src/controllers/auth.ts`](file:///c:/Users/Admin/Downloads/YourStore/apps/api/src/controllers/auth.ts)<br>[`apps/api/src/models/User.ts`](file:///c:/Users/Admin/Downloads/YourStore/apps/api/src/models/User.ts) |
| **Token theft and refresh reuse** | 15-minute access token and 7-day refresh token stored in `httpOnly`, `Secure`, `SameSite=Lax` cookies (never `localStorage`). Refresh token stored only as SHA-256 hash. Automatic reuse detection revokes all sessions and wipes the hash on reuse. | [`apps/api/src/lib/token.ts`](file:///c:/Users/Admin/Downloads/YourStore/apps/api/src/lib/token.ts)<br>[`apps/api/src/controllers/auth.ts`](file:///c:/Users/Admin/Downloads/YourStore/apps/api/src/controllers/auth.ts)<br>[`apps/api/src/models/User.ts`](file:///c:/Users/Admin/Downloads/YourStore/apps/api/src/models/User.ts) |
| **CSRF** | Mandatory custom header validation (`X-Requested-With` or `X-CSRF-Token`) on all state-changing HTTP requests (`POST`, `PUT`, `PATCH`, `DELETE`). External webhooks are exempted. | [`apps/api/src/middleware/csrf.ts`](file:///c:/Users/Admin/Downloads/YourStore/apps/api/src/middleware/csrf.ts)<br>[`apps/web/lib/api.ts`](file:///c:/Users/Admin/Downloads/YourStore/apps/web/lib/api.ts) |
| **XSS and CSP** | Helmet with a strict Content Security Policy (`defaultSrc: ['self']`, `scriptSrc: ['self']`, `objectSrc: ['none']`, `frameAncestors: ['none']`, `imgSrc: ['self', 'data:', 'https://res.cloudinary.com']`). Strict `X-Content-Type-Options: nosniff`. React escapes output by default. | [`apps/api/src/middleware/security.ts`](file:///c:/Users/Admin/Downloads/YourStore/apps/api/src/middleware/security.ts) |
| **NoSQL injection** | `express-mongo-sanitize` strips keys containing `.` or starting with `$` from `body`, `query`, and `params`. All queries use Mongoose models with strict schema typing and Zod payload validation. | [`apps/api/src/middleware/security.ts`](file:///c:/Users/Admin/Downloads/YourStore/apps/api/src/middleware/security.ts)<br>[`apps/api/src/middleware/validate.ts`](file:///c:/Users/Admin/Downloads/YourStore/apps/api/src/middleware/validate.ts) |
| **IDOR (Insecure Direct Object References)** | Scoped queries ensure users can only access or mutate their own resources (orders, addresses, reviews, wishlist). Admin routes enforce `requireRole('admin')`. | [`apps/api/src/controllers/orders.ts`](file:///c:/Users/Admin/Downloads/YourStore/apps/api/src/controllers/orders.ts)<br>[`apps/api/src/controllers/enquiries.ts`](file:///c:/Users/Admin/Downloads/YourStore/apps/api/src/controllers/enquiries.ts)<br>[`apps/api/src/middleware/auth.ts`](file:///c:/Users/Admin/Downloads/YourStore/apps/api/src/middleware/auth.ts) |
| **Price tampering** | Product prices, discounts, taxes, and shipping are computed strictly server-side using authoritative database records and active coupons. Client-provided prices are completely ignored. | [`apps/api/src/controllers/checkout.ts`](file:///c:/Users/Admin/Downloads/YourStore/apps/api/src/controllers/checkout.ts)<br>[`apps/api/src/controllers/orders.ts`](file:///c:/Users/Admin/Downloads/YourStore/apps/api/src/controllers/orders.ts) |
| **Stock race conditions** | Atomic MongoDB updates (`$inc: { stock: -qty }` with condition `stock: { $gte: qty }`) prevent overselling under concurrent checkouts. Compensating atomic transactions restore stock on order cancellation or payment failure. | [`apps/api/src/controllers/checkout.ts`](file:///c:/Users/Admin/Downloads/YourStore/apps/api/src/controllers/checkout.ts)<br>[`apps/api/src/services/order.ts`](file:///c:/Users/Admin/Downloads/YourStore/apps/api/src/services/order.ts)<br>[`apps/api/src/controllers/adminOrders.ts`](file:///c:/Users/Admin/Downloads/YourStore/apps/api/src/controllers/adminOrders.ts) |
| **Stripe webhook forgery and replay** | Webhook requests require raw payload verification using Stripe's official SDK (`stripe.webhooks.constructEvent`) and `STRIPE_WEBHOOK_SECRET`. Processed event IDs are tracked in `WebhookEvent` with unique constraints for idempotency. | [`apps/api/src/controllers/checkout.ts`](file:///c:/Users/Admin/Downloads/YourStore/apps/api/src/controllers/checkout.ts)<br>[`apps/api/src/index.ts`](file:///c:/Users/Admin/Downloads/YourStore/apps/api/src/index.ts) |
| **Upload abuse** | Client does not receive raw Cloudinary API credentials. Instead, backend signs upload parameters using `cloudinary.utils.api_sign_request` only for authenticated admins, enforcing folder, timestamp, and asset size limits. | [`apps/api/src/controllers/upload.ts`](file:///c:/Users/Admin/Downloads/YourStore/apps/api/src/controllers/upload.ts)<br>[`apps/api/src/routes/admin.ts`](file:///c:/Users/Admin/Downloads/YourStore/apps/api/src/routes/admin.ts) |
| **CSV formula injection** | Rows are scanned for formula triggers (`=`, `+`, `-`, `@`, `\t`, `\r`) at the start of text cells. Any row containing formula characters is rejected or sanitized before parsing. Data is never evaluated. | [`apps/api/src/controllers/adminProductImport.ts`](file:///c:/Users/Admin/Downloads/YourStore/apps/api/src/controllers/adminProductImport.ts) |
| **Regex injection (ReDoS)** | Dynamic user input is escaped using `escapeRegex` before constructing MongoDB regular expression queries. | [`apps/api/src/lib/regex.ts`](file:///c:/Users/Admin/Downloads/YourStore/apps/api/src/lib/regex.ts)<br>[`apps/api/src/controllers/adminOrders.ts`](file:///c:/Users/Admin/Downloads/YourStore/apps/api/src/controllers/adminOrders.ts)<br>[`apps/api/src/controllers/adminLists.ts`](file:///c:/Users/Admin/Downloads/YourStore/apps/api/src/controllers/adminLists.ts) |
| **Secrets in repo** | All sensitive configurations (database URIs, Stripe keys, JWT secrets, Resend tokens) are loaded from environment variables validated at startup. `.env*` files are ignored in `.gitignore`, and CI uses dummy test credentials. | [`.gitignore`](file:///c:/Users/Admin/Downloads/YourStore/.gitignore)<br>[`apps/api/src/env.ts`](file:///c:/Users/Admin/Downloads/YourStore/apps/api/src/env.ts)<br>[`.github/workflows/ci.yml`](file:///c:/Users/Admin/Downloads/YourStore/.github/workflows/ci.yml) |
| **Dependency vulnerabilities** | Automated weekly vulnerability scanning using Dependabot for npm packages and GitHub Actions. CI includes `npm audit --omit=dev --audit-level=critical`. | [`.github/dependabot.yml`](file:///c:/Users/Admin/Downloads/YourStore/.github/dependabot.yml)<br>[`.github/workflows/ci.yml`](file:///c:/Users/Admin/Downloads/YourStore/.github/workflows/ci.yml) |

## Known issues

`npm audit` reports advisories on `postcss` (bundled transitively in Next.js 15) and minor `zod` advisories pending upstream patch releases and the Next.js major version upgrade path. These are audited and non-exploitable in the current deployment configuration.
